# Vértice Automóveis

Static front-end concept for a multi-brand car dealership, with a vehicle catalogue, search filters, favourites, vehicle details, and a demo stock-management panel.

## Open locally

Open `index.html` in a browser. The management panel is at `admin/index.html`.

## Demo limitations

The admin login and stock data are front-end demonstrations stored in the browser's `localStorage`. They are not secure authentication or a shared database and must not be used to protect real customer or business data.
